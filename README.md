# Role Prompt Workbench

A small, independent Codex skill for turning a job task and its real context into a reusable AI prompt.

## Install

Copy `role-prompt-workbench/` into your Codex skills directory. The skill is self-contained; it has no runtime dependencies.

## Use

Invoke `$role-prompt-workbench` when you want a copy-ready prompt tailored to a role, task, audience, inputs, and constraints.
